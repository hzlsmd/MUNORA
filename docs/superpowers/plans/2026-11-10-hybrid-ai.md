# Hybrid AI Recommendations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add free-tier AI recommendations to the existing weather activity planner with deterministic hazards and outage fallback.
**Architecture:** Flutter submits bounded plan/weather context to a Cloudflare Worker; Gemini supplies supplementary text. Rules remain authoritative. Persistent atomic quota reservations protect the free deployment.
**Tech Stack:** Flutter/Dart, existing http package, JavaScript modules, Node built-in test runner, Cloudflare Workers/Durable Objects, Gemini REST API.
**Spec:** docs/superpowers/specs/2026-11-10-hybrid-ai-design.md

## Global Constraints
- No paid service or billing activation; provider model configured at deployment after checking account free-tier availability.
- Keep API key out of Flutter, source control and logs.
- Preserve app-generated hazards and existing fallback tips.
- Explicit AI request only; no automatic polling or background AI notifications.
- Reject stale, incomplete, mismatched or oversized inputs/output.

## Review Focus
- Plan/city/forecast changes during an outstanding generation must discard its result.
- A storm between display samples must still trigger rules and notifications.
- Concurrent quota reservations cannot overspend the daily cap.
- Expired cache or provider errors cannot be displayed as fresh AI advice.
- Missing service/key configuration leaves a useful rule-based planner.
