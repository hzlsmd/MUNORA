# Design assets

Unmodified PNG and SVG assets from the user-supplied MUNORA.zip Figma Make export,
used by the native Flutter UI. Filename identifiers are retained for traceability.
Only assets referenced by the implemented screens are included. Dynamic weather
icons select the matching supplied symbol for the provider's condition.

Inter and Abyssinica SIL are bundled separately under assets/fonts, each with its
SIL Open Font License. No temporary Figma URLs are required at runtime.
