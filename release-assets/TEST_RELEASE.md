MUNORA Android test build from master (`00d41fb`).

Download **munora-arm64-v8a-debug.apk** for most modern Android phones. The QR image opens that APK download directly. This package supports ARM64 Android phones; it is not an x86 emulator or older 32-bit phone build.

This is a debug-signed test prerelease, not a production-signed release. It includes forecast Alerts/Tips, prediction agreement levels, activity personalization, local routines/feedback, Firebase removal, and the latest startup styling. The MUNORA splash remains five seconds; Android controls the preceding system startup duration.

Install only on a device where you intend to test MUNORA. Android may ask you to allow installation from your browser. If an existing MUNORA installation uses another signing key, Android may reject the update; uninstalling it first removes its locally saved preferences and routines.

The APK is built by Flutter/Gradle, but has not been launch-tested on a phone or emulator in this workspace. No production signing key is included.
